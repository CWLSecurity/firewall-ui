Low-value first run

Try Firewall Vault safely before trusting meaningful funds

Security products should earn trust gradually. This page gives you a small test flow that shows the main behavior without asking you to move meaningful assets first.

Recommended first test amount

Start with a very small amount, such as 0.001 to 0.01 ETH on Base. Use enough to cover gas and a simple test, not enough to create stress.

Safe trial flow

1

Create or import a Vault

  1. Connect the wallet you want to test with.
  2. Create a new Vault or import an existing one.
  3. Choose the protection mode you want to understand first.
2

Fund only the test amount

  1. Open Receive.
  2. Copy the Vault address or send directly from the connected wallet.
  3. Confirm that the Vault balance updates.
3

Trigger a reviewable action

  1. Send a small amount from the Vault to a new address you control.
  2. Watch whether the policy delays it and creates a queue item.
  3. Open the queue and inspect the reason and unlock time.
4

Practice queue control

  1. Cancel the delayed action if you want to test stopping an outflow.
  2. Or wait until unlock and execute it manually.
  3. Only enable automation after you understand manual execution.

What you should learn from this test

Signer vs Vault

Your wallet signs. The Vault holds funds and applies rules.

Queue behavior

A delayed action is not lost. It waits in queue until it can be executed or canceled.

Automation boundary

Automation helps execute unlocked actions. It does not get open access to Vault funds.

When to move more funds

Move more only after you are comfortable with create/import, receive, send, queue review, cancel, manual execute, and the current security status.
