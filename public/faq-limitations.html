FAQ & Limitations

Clear answers before you use Firewall Vault

Firewall Vault adds enforceable on-chain controls, but it is not magic and not insurance. This page keeps the most important user questions and limitations in one place.

Common questions

Is Firewall Vault a wallet?

It is a protected Vault controlled by your connected signer wallet. Your wallet signs actions. The Vault holds funds and applies protection rules before outgoing actions execute.

Can Firewall Vault recover stolen funds?

No. Firewall Vault can delay or block selected outgoing actions before they execute. It cannot recover funds after they have already left the Vault.

Can automation withdraw my funds?

No. Automation can only execute already-unlocked queued actions through the authorized executor path. It does not get arbitrary withdrawal access to the Vault.

Why was my action delayed?

It matched an active protection rule, such as a first transfer to a new address, a larger transfer, a first-time approval, or an unfamiliar action in DeFi Trader mode. Open the queue item to see the reason and unlock time.

Can I disable a protection?

The base protection mode is selected when the Vault is created. Optional add-ons are additive in the current line. Treat enabled add-ons as persistent unless the UI and contract line explicitly support removal later.

What happens if I lose my signer wallet?

Current recovery is reserved metadata only. There is no active recovery authorization flow in the MVP. Protect your signer wallet and seed phrase carefully.

Is Firewall Vault audited?

Assume the current MVP is not externally audited unless a later public status page explicitly says otherwise. Test with low-value flows before using meaningful funds.

Does it work with every dApp?

Not yet. The current MVP focuses on the Firewall Vault UI on Base. Broader connector and partner dApp integrations are a later rollout track.

Important limitations

  • Firewall Vault is not insurance.
  • Firewall Vault does not protect a compromised device, browser, wallet extension, seed phrase, or private key.
  • Delays create review time, but they do not guarantee that every bad action is prevented.
  • The MVP is Base Mainnet only.
  • The current recovery field is not an active recovery system.
  • Users should verify addresses, source code, and transaction details before trusting meaningful funds.

Support and security reports

For security reports, use security@firewallvault.io. Include a description, reproduction steps, affected component or contract, and impact.

Never send seed phrases, private keys, or raw wallet secrets to anyone.
